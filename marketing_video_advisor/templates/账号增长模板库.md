# 账号增长中心 - 模板库

> 所有模板由 agent 按客户信息填充，输出可直接复制使用的内容。

## 一、账号战略卡模板

```text
账号名称：{建议名称}
账号身份：{城市} + {行业} + {身份}（如：太原产业园招商主管 / 企业选址顾问）
目标客户：{行业 + 企业规模 + 预算范围 + 决策人 + 城市}
内容主线：{2-4 条主线，如：选址判断 + 园区实景 + 独栋产品 + 企业案例}
转化动作：{私信关键词 / 预约实地考察 / 获取项目资料}
内容边界：{拍什么 / 不拍什么}
```

## 三、对标卡模板

```text
# 对标账号卡
账号：{名称}　平台：{抖音/视频号}　来源：{链接}　抓取时间：{时间}
行业/地区：{…}
适合参考：{哪类内容值得学}
有效开头：{拆解其爆款开头结构}
镜头结构：{其镜头顺序}
话术结构：{其表达逻辑}
可借鉴点：{可复用的结构}
不能照搬：{价格/名称/夸大承诺}
为本账号改写：{替换成我们的真实卖点}
```

对标来源标记：每条结论注明来源链接 + 抓取时间；无法核实处标注"待人工核实"。

## 六、内容计划模板（30 天）

```text
# 30 天内容计划
账号定位：{战略卡摘要}

## 节奏
每周 3-5 条：周一二 产品带看 / 周三四 企业选址 / 周五 园区进展 / 周末 客户问题或信任内容

## 内容排期（示例）
第 1 天｜产品带看｜850 万独栋值不值｜执行卡见 …
第 2 天｜企业选址｜什么企业适合独栋
第 3 天｜园区进展｜交付节点
…

## 复用规则
- 每类内容一套镜头结构模板，换主题即可
- 数据更新时（价格/交付）及时替换
```

## 七、问答库与合规规则

```text
# 高频问答库
Q: 还有多大面积？
A: 目前可根据企业阶段匹配不同面积段。您是更偏办公展示，还是生产办公一体？我按需求给您筛一套。

Q: 价格多少？
A: 不同位置、面积和付款方式会有差异。您大概预算和用途方便说一下吗？我把合适的方案整理给您。

Q: 能去看吗？
A: 可以。您一般工作日还是周末方便？我提前把独栋、露台和园区动线安排好，您现场一次看清楚。

Q: {客户常问} A: {引导留资回复}
（企业可自行维护真实数据）

# 合规规则（写死）
1. 不承诺收益、升值或政府补贴
2. 不写未经确认的价格、面积、交付期
3. 不用夸张绝对化词语（最/第一/绝对/唯一）
4. 抖音受限词、行业禁词：{按平台当期规则维护}
5. 不引导违规站外交易
6. 所有对外数据（价格/面积/政策）须经企业确认后发布
```
