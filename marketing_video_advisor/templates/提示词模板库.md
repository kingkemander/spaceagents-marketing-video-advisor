# 生视频提示词模板库（专业级）

> 依据：火山方舟《Doubao Seedance 2.5 提示词指南》＋阿里 Wan 3.0 多参考实践＋实战打磨的专业级提示词
> 粒度说明：所有模板按「专业级」标准书写（对标电影级详细度）。如需要快速版，删减光线/声音细节即可。
> 调用：用户给文案/选题 → AI 按栏目选模板 → 文案入轴并按专业规范补全细节 → convert.py 组装 → 出片。

## 〇、专业级写作规范（AI 生成提示词的检查清单）

### 0.1 素材参考：区分「锁定」与「仅参考」
- 必须逐素材标注角色：`图1@锁定人物身份（全程不变脸不换装）`、`图2@仅参考园区道路与绿化布局`、`图3@锁定独栋外立面`、`图4@参考露台空间`、`音频1@人物音色参考`
- 人物/核心建筑用「锁定」；氛围/布局类用「仅参考」——防止模型把次要素材画死

### 0.2 每段时间轴段落的骨架（七要素）
每段（2-4 秒小段 / 5-10 秒大段）依次写全：
1. **景别开局**：中近景/近景/全景/特写…
2. **主体动作**：走位、手势、转身、微笑、驻足…（写具体动词，不用"自然地"）
3. **机位运镜**：稳定器跟拍(walk-and-talk)/低到高/极轻前推/焦点转换/环绕/手持…
4. **光线细节**：低角度金色阳光/玻璃幕墙反光/日光光影扫过/云影掠过后回稳/逆光剪影…
5. **背景交代**：前景虚化程度/背景建筑与主体关系/环境纵深…
6. **台词**：「」（需唇形同步的段，注明"驻足时镜头稳定利于口型同步"）
7. **声音**：本段环境声/脚步/气声/切点节拍…

### 0.3 声音设计（独立段落）
- 贯穿声：什么时段的光线/氛围（如"金色时段环境声贯穿全片"）
- 分层：环境声 + 动作声 + 人声；写明"对白清晰、无配乐干扰、字幕后期加"（或"不要字幕"）
- 切点：转场处配轻微气声/节拍点，制造节奏

### 0.4 负面约束：全维度清单（照抄+按场景增删）
**人物类**：人物不变脸、不换装、不出现多人、步伐自然不滑步不飘浮、不夸张挥手、口型同步
**场景类**：建筑不变形、无住宅小区感、无室内穿帮（室外场景时）、无乱码文字
**画面类**：无字幕（或注明后期加）、无价格浮层、无电话/二维码/水印、无卡通感
**镜头类**：无快速运镜、无复杂转场、无远景航拍（不需要气势时）、无大场面空镜
**合规**：不承诺收益/升值、不写未确认数据（价格面积需客户确认）

### 0.5 时长×内容量配比（防剪切防遗漏）
- 2-3 秒：1 个动作或 1 句短台词
- 4-7 秒：1 个完整动作 + 1-2 句台词
- 8-10 秒：2-3 个连续动作 + 2-3 句台词 + 1 次运镜变化
- 30 秒长片：建议 3-5 段，避免"每段塞太多"

## 一、产品带看（专业级标杆 · 实战验证模板）

> 来源：已实战打磨的高质量样例，作为「详细到什么程度」的基准。可直接替换产品信息使用。

```
【风格】实拍高端商业地产宣传片质感，手持相机拍摄风格，低饱和暖冷对比、受控高对比；自然晴天金色光，浅景深，玻璃幕墙反光与橙色线条干净锐利；高级、克制、实地带看调性。全程硬切，不做复杂转场，无字幕。全片仅用中景与近景，不用远景、不用航拍。
【参考】图1@锁定人物身份；图2@仅参考园区道路与绿化布局；图3@锁定独栋外立面；图4@参考露台空间。音频1@人物音色参考。
【时间轴】
0-3s｜引向独栋：中近景，人物从画面里朝独栋方向走动，镜头以稳定器近距跟拍（walk-and-talk），人物居中、边走边看向镜头，行进中以手轻指前方独栋；低角度金色阳光打在玻璃与橙色线条上，浅景深把背景建筑作轻度虚化。台词：「{价格钩子，如：850万，买一栋1400平米的独栋。}」（步伐自然、不滑步不飘浮）声音：园区环境声、轻风、脚步轻微节奏。
3-7s｜驻足独立入口：硬切，中近景，人物在独栋入口/玻璃幕墙前驻足，镜头由低到高轻微带出外立面纵向体量与独立入口；人物回身看建筑，走近一步让日光玻璃光影扫过身，再面向镜头，手掌朝独立入口小幅展开。台词：「{卖点，如：独立入口、独立动线，1400平的体量，办公展示都够用。}」（驻足时镜头趋于稳定，利于唇形同步）声音：轻风、树叶细响，一次低频气声落切点。
7-10s｜露台俯瞰：硬切，露台入口外侧近景，人物走至露台栏杆边、手扶栏杆，镜头极轻前推并做一次焦点转换：从前景绿植/栏杆缓缓过渡到露台与远处园区、天际线；人物转身朝露台看一眼，再面向镜头，以手轻轻示意开阔露台，最后自然微笑；一次云影掠过天空，光线一亮再回稳。台词：「{亮点，如：还带约300平露台，接待展示都很有面子。}」声音：高空风声、远处城市低鸣，结尾干净收束。
【声音】金色时段环境声贯穿全片，轻风、脚步节奏、远处园区低鸣；三处切点各配轻微气声/节拍点；对白清晰、无配乐干扰，字幕后期加。
【负面约束】人物不变脸、不换装、不出现多人、步伐自然不滑步不飘浮、不夸张挥手、口型不同步、建筑变形、住宅小区感、室内、乱码文字、字幕、价格浮层、电话、二维码、水印、卡通、快速运镜、复杂转场、远景、航拍、大场面空镜。
```

**复用方法**：把 {价格钩子}{卖点}{亮点} 换成你的真实产品信息（价格/面积需客户确认后再写），其余结构照用。

## 二、数字人口播（知识干货/客户问题 · 专业版）

```
【风格】实拍商业口播质感，画面干净明亮，低饱和中性调、轻微冷青倾向，受控对比；窗边自然光为主光源，人物面部受光均匀、无顶光硬影；浅景深，背景办公/园区轻度虚化不抢主体；高级、可信、知识分享调性。全程硬切，无复杂转场，无字幕（字幕后期加）。全片中景与近景为主。
【参考】图1@锁定人物身份；图2@仅参考产品场景（背景板）；图3@仅参考配套/数据图表氛围。音频1@人物音色参考。
【时间轴】
0-4s｜开场钩子：中景，人物正面立于场景中，站姿自然双手自然垂放或轻抬示意，镜头固定微推（0.5-1m）；人物看向镜头开口。台词：「{钩子，疑问句/反常识}」声音：环境声低铺，人声清晰切入。
4-12s｜要点输出：中景，人物保持中景，讲到要点时小幅手势辅助（手掌开合示意数字），镜头极轻微左右平移（手持呼吸感）；背景第3秒可插入图2实景一闪（0.5s叠化或不叠直接硬切回来）。台词：「{要点1+要点2}」声音：人声为主，间隙保留轻微环境声。
12-20s｜场景佐证：近景切图2/图3实景2-3秒后切回人物近景，人物看向镜头继续输出；人物表情专注、自然眨眼。台词：「{要点3+结论}」声音：场景段保留现场环境声，切回人声清晰。
20-30s｜CTA收尾：近景，人物收势：微微前倾、双手自然并拢，点头一次；镜头缓慢推至近景定格。台词：「{CTA：引导评论区/私信}」声音：人声收束，尾音干净，可配一声轻提示音（后期）。
【声音】整体人声清晰无配乐干扰；环境声低铺贯穿（室内白噪/空调低鸣量感极低）；三段切点干净，无回音。
【负面约束】人物不变脸、不换装、不出现多人、口型同步、动作不夸张、肢体不穿帮；无字幕浮层、无价格浮层、无电话二维码水印；背景不乱入人群、无杂乱杂物、无手机震动提示、无卡通元素；无快速运镜、无复杂转场、无远景空镜。
```

## 三、金句情绪片（情绪共鸣/人设 · 专业版）

```
【风格】情绪短片质感，电影感色调（低饱和暖冷对比、暗部带青），开场黑底白字金句衬线体居中，后转实拍；主光源为侧逆光（发丝光），人物面部半明半暗有立体感；浅景深，中近景为主；克制、有留白、不煽情过度。
【参考】图1@锁定人物身份；图2@仅参考地标/建筑氛围；图3@仅参考空间细节（光影/材质）。音频1@人物音色参考。
【时间轴】
0-4s｜金句开场：纯黑底，白字金句逐字浮现（排版：居中两行，衬线体），无人物无声音，只留极低底噪（房间低频）。
4-12s｜人物诉说：硬切，中景，人物坐在窗边（或站于建筑前），侧逆光勾勒轮廓，面朝镜头；镜头固定，人物缓慢抬头看向镜头开口；眼中有光、表情克制。台词：「{叙事1：过去的艰难}」声音：窗外环境声（风/远处车流）低铺，人声清晰。
12-20s｜象征画面：硬切，图2地标/图3光影细节交替各2-3秒（慢镜或缓推），无人物；云影/光斑缓缓移动，象征时间与坚持。台词（旁白延续，不出镜）：「{叙事2：选择与坚守}」声音：环境声延续，情绪音乐低音量起（后期BGM）。
20-30s｜人物收尾：硬切回人物近景，人物平视镜头，极轻微笑；镜头缓推定格。台词：「{CTA或金句收尾}」声音：人声收，BGM渐弱至尾音干净。
【声音】开场极静；中段环境声+低音量情绪BGM；尾段人声清晰、BGM渐出；整体无突兀音效。
【负面约束】人物不变脸、不换装、不出现多人、口型同步、不夸张表演；无字幕（除开场金句文字，后期可加）；无价格浮层、无电话二维码水印；光线不过曝、肤色不失真；无卡通、无快速运镜、无复杂转场。
```

## 五、词库（组装时选用）

### 景别
大全景（气势）｜全景（环境+人物）｜中景（腰部上）｜中近景（胸上+手部动作）｜近景（面部+表情）｜特写（局部）

### 机位运镜
推/拉/摇/移/跟｜稳定器跟拍 walk-and-talk｜低机位仰拍（气势/纵向体量）｜俯拍｜极轻前推｜后拉｜上摇｜环绕｜焦点转换（移焦）｜手持呼吸感｜一镜到底｜航拍｜云台横移

### 光线（按时段与质感写）
金色时段（日出日落低角度）｜侧逆光/发丝光｜窗边自然光｜玻璃反光流动｜日光光影扫过｜云影掠过光线一亮再回稳｜顶光（少用，易出硬影）

### 情绪与调性词
高级、克制｜温暖｜可信｜有力量｜留白｜不煽情过度｜干净利落｜纪实真实

### 声音分层
环境声（风/车流/园区低鸣/脚步/树叶/机械）｜动作声（气声/节拍点）｜人声（对白/旁白）｜配乐（BGM，后期加）——每层可独立控制

### 负面约束（全清单模板，按场景增删）
人物不变脸、不换装、不出现多人、步伐不滑步不飘浮、不夸张挥手、口型同步；建筑不变形、住宅小区感、室内穿帮、乱码文字；字幕、价格浮层、电话、二维码、水印、卡通；快速运镜、复杂转场、远景空镜、航拍、大场面空镜。

## 六、AI 组装流程（默认专业级）

1. 用户给文案/选题 → 判断栏目
2. 选场景模板（一~四）→ 按需切换 专业版/标准版
3. 文案按 0.5 配比切进时间轴；素材按 0.1 规则标注锁定/参考
4. 按 0.2 七要素补全每段（景别/动作/运镜/光线/背景/台词/声音）；按 0.3 写声音段；按 0.4 写负向清单
5. 检查：时间戳连续、指代与素材顺序一致、台词「」引用、无跳段
6. 输出执行卡 JSON → convert.py 组装 → 用户确认 → 出片
